設計図の操作：メニュー＋α の 2 案

前回の 4 案（長押し＋ホイール / ラジアルメニュー / 併用 / 棒）を踏まえた折衷案です。どちらも同じ設計図メニューを使い、メニューからは設定画面で配置・範囲についてできることのほとんどに届きます。 違いはメニューの外の操作で、E は機能ごとの個別キー（任意）、F は「直前の調整をホイールで繰り返すキー」を別に持ちます。ワールドをクリックしてから試してください。

確認したいこと

  • E と F のどちらが良いか（両方入れて、個別キーも調整キーも任意にする手もある）。
  • メニューの分類と項目（下の表）に足りないもの・要らないものはないか。
  • 「移動」は動かす対象（選択中の配置 / 角 1 / 角 2 / 範囲全体）に効く形でよいか。
  • メニューを開いている間はゲームが止まらない（今の Lamium の画面と同じくマウスを奪うだけ）想定でよいか。
